# 岐黃尋 — 中醫典籍全文檢索

純前端（靜態網頁）中醫典籍檢索工具。輸入病名、藥名、方劑名或任意關鍵字，都能在 803 部典籍全文中找出出現的段落；並自動提示古今病名對照。搜尋預設會把簡體字、常見中醫異體字（例如「蟅／䗪」「黃芪／黃耆」「鱉甲／鼈甲」）自動正規化比對，不論輸入或原文用哪種寫法都找得到。

## 專案結構

```
.
├── index.html          # 主頁面
├── style.css           # 樣式（設計系統：宣紙、墨、硃砂印）
├── app.js              # 前端邏輯（全文檢索、對照、閱讀器）
├── README.md
└── data/
    ├── books-index.json       # 803 部典籍的中繼資料（書名/作者/朝代/分類），約 1.1MB，頁面載入時直接讀取
    ├── disease-map.json       # 118 筆古今病名對照表（可自行擴充）
    ├── char-normalize-map.json # 簡體字／中醫常見異體字 → 正規化字對照表，約 30KB，頁面載入時直接讀取
    ├── bigram-shards/         # 全文雙字元（bigram）索引，依首字切成約 1 萬個小檔案，搜尋時才依需要下載對應分片
    └── books/                  # 803 個典籍內容檔（每部書一個 JSON），使用者點開某本書、或搜尋驗證時才會下載
```

資料來源：中醫笈成（jicheng.tw）公開典籍資料，共 803 部、約 8700 個篇章、約 1 億零 200 萬字。

## 如何運作（全文檢索）

1. 頁面載入時只抓取 `books-index.json`、`disease-map.json`、`char-normalize-map.json`，總計約 1.2MB，速度很快。
2. 使用者輸入關鍵字時：
   - 先把輸入字串正規化（簡體轉繁體 + 中醫異體字統一），例如「大黄虫丸」會被視為「大黃蟲丸」。
   - 同時比對 `disease-map.json`：若輸入的是現代病名，會列出對應的古代病名（反之亦然），並把這些古代病名一併加入搜尋。
3. 把正規化後的查詢字串拆成連續雙字元（bigram），依序向 `data/bigram-shards/` 下載對應分片，取出「可能包含這個字串」的候選典籍清單（多字查詢會逐一取交集，愈長愈精準）。
4. 平行下載候選典籍的全文（`data/books/書名.json`，有快取，最多同時 12 筆），實際在全文中比對出現位置與次數，並記錄該書實際使用的寫法（可能跟輸入的寫法不同，例如原文寫「䗪蟲」而你輸入「蟅蟲」）。
5. 點擊某本典籍時，用剛剛驗證比對到的實際寫法在內文中標出符合的詞語，支援上一個/下一個跳轉。

這樣設計是因為全部典籍解壓後約 290MB、bigram 索引解壓後約 100MB，都不適合一次全部載入瀏覽器；改成「先查小索引、再依需要下載內容」，讓純靜態網站（GitHub Pages）也能提供接近全文搜尋引擎的體驗。

## 已知限制

- 候選典籍數量上限為 80 部（`MAX_CANDIDATE_BOOKS`），極常見的關鍵字（例如「中風」「咳嗽」這類高頻詞，可能出現在 600 部以上典籍中）搜尋結果只會顯示前 80 部驗證到的典籍，不保證涵蓋全部；關鍵字愈具體（方劑名、藥名組合等），結果愈完整精準。
- 異體字對照表（`char-normalize-map.json`）是人工整理的常見中醫用字對照，並非窮舉所有古籍異體字，如發現遺漏歡迎自行擴充這份檔案（格式為 `{"異體字": "正規化字"}`，需為單字對單字）。
- 簡繁轉換使用 OpenCC 標準字表產生，多字詞、成語等一對多轉換情形不在處理範圍內（僅做單字對單字轉換）。

## 部署到 GitHub Pages

### 方法一：使用 Git 指令（建議，檔案數量多時比網頁上傳穩定）

```bash
# 1. 在 GitHub 上新增一個空的 repository，例如命名為 tcm-jicheng-search
#    （不要勾選自動加入 README/.gitignore）

# 2. 進入這個資料夾，初始化 git
cd 岐黃尋   # 或你解壓縮後的資料夾名稱
git init
git add .
git commit -m "建立中醫典籍病名檢索網站"

# 3. 連結到你的 GitHub repo（記得換成你自己的帳號與 repo 名稱）
git branch -M main
git remote add origin https://github.com/你的帳號/tcm-jicheng-search.git
git push -u origin main
```

> 65MB 壓縮檔解開後變成很多獨立小檔案，`git push` 第一次會花一點時間上傳（約 300MB），請保持網路穩定，不要中斷。

### 開啟 GitHub Pages

1. 到你的 repo 頁面 → **Settings** → 左側選單 **Pages**
2. **Source** 選擇 `Deploy from a branch`
3. **Branch** 選擇 `main`，資料夾選擇 `/ (root)`，按 **Save**
4. 等待 1–2 分鐘，頁面會顯示網址，格式通常是：
   `https://你的帳號.github.io/tcm-jicheng-search/`

### 之後更新資料或程式碼

```bash
git add .
git commit -m "更新內容"
git push
```

## 之後可以擴充的方向

- **擴充病名對照表**：直接編輯 `data/disease-map.json`，格式為：
  ```json
  {"modern": "現代病名", "ancient": ["古代病名1", "古代病名2"], "note": "說明文字（可留空字串）"}
  ```
  新增後不需要重新處理典籍資料，重新整理頁面即可生效。

- **重新產生全文索引**：若日後要更新典籍資料本身，`data/books/` 與 `data/term-index.json` 是由原始 .7z 檔案透過 Python 腳本自動產生的（腳本邏輯：解析 DokuWiki 格式標記、擷取 `<book>` 中繼資料、掃描病證詞彙建立索引）。若你需要，我可以之後幫你把產生腳本一併整理進repo（例如 `scripts/build_data.py`），方便未來更新典籍時重新產生。

- **免責聲明**：頁面下方已加註「古今病名對照僅供臨床參考與文獻檢索輔助」的提醒，建議正式對外使用前，可請中醫師審閱 `disease-map.json` 的對照內容是否恰當。
